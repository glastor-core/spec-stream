§spec-stream-core

Core primitives, data structures, and mathematical verification algorithms for speculative decoding in high-throughput Large Language Model (LLM) inference.

Designed to be model-agnostic, zero-allocation where possible, and strictly compliant with exact output probability distributions (Leviathan et al., 2023).
