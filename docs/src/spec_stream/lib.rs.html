1//! # spec-stream
2//!
3//! **spec-stream** is an ultra-fast, modular, model-agnostic speculative decoding and
4//! paged KV-cache engine in pure Rust.
5//!
6//! Accelerates Large Language Model (LLM) inference by 2x–3x through speculative token burst
7//! verification and $O(1)$ rollback paged memory allocation.
8//!
9//! ## Key Capabilities
10//! - **Mathematical Exactness**: Implements Leviathan et al. (2023) stochastic rejection sampling,
11//!   guaranteeing output probability distribution identical to the target model.
12//! - **Paged KV-Cache with O(1) Rollback**: Physical-to-virtual block tables prevent memory fragmentation
13//!   and allow instant rewind of rejected speculative proposals.
14//! - **Model Agnostic**: Plug in any inference backend: Candle, Burn, ONNX Runtime, or native C/CUDA FFI.
15//! - **Async Token Streaming**: First-class support for Tokio streams and Server-Sent Events (SSE).
16
